Reproduce

python3 -m bpp.datasets data
python3 -m bpp.train --data cut1 --name cut1_v2 --iters 120 --games 512 \
    --sims 100 --c_puct 4.0 --dir_eps 0.05 --temp_moves 0
python3 -m bpp.evaluate runs/cut1_v2/last.pt cut1 --reps 3 \
    --sims 100 --c_puct 4.0 --out results/cut1_final_last.json
python3 report.py
python3 -m bpp.viz.report --packing cut1 cut2 rs
Play the agent yourself with python3 -m bpp.viz.game, or watch a run train with python3 -m bpp.viz.dashboard.
